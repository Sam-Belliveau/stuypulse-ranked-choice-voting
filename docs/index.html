Ranked Choice Voting

How to Use This Tool

1. Set Up Your Google Form

  • Add one Dropdown question per rank.
  • Title each question with its rank digit, e.g. 1st Choice, 2nd Choice, 3rd Choice, 4th Choice, etc.
  • Populate each dropdown’s options with the exact list of candidate names.

2. Export Ballots as CSV

  1. In Google Forms, click the “Responses” tab → click the Sheets icon to open the linked spreadsheet.
  2. In the spreadsheet menu: File → Download → Comma-Separated Values (.csv).
  3. Save that CSV to your computer.

3. Upload & Run Election

  • Click “Choose File” below and select your downloaded CSV.
  • Hit “Run Election” to see the ranked-choice results instantly.

What You’ll See

The results pane will display each elimination round. • All candidates are listed in descending order of votes for that round. • The candidate with the fewest votes is then removed, and ballots are re-allocated to voters’ next preferences. • Rounds continue until one candidate remains.
