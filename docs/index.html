StuyPulse – Ranked Choice Voting Tool

This tool lets you count ranked-choice votes from a Google Form and is approved for use in elections consistent with the StuyPulse Charter.

Step 1. Set Up Your Google Form

  • Add one Dropdown question per rank.
  • Title each question with the digit of the rank, e.g. 1st Choice, 2nd Choice, 3rd Choice...
  • Populate each dropdown’s options with the exact list of candidate names.

Step 2. Export Ballots as CSV

  1. In Google Forms, go to the “Responses” tab
  2. Click the Sheets icon to open the linked spreadsheet.
  3. Click File → Download → Comma-Separated Values (.csv).
  4. Save that CSV to your computer.
